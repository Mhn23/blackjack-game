# 🃏 Blackjack Game

A classic Blackjack web application built from scratch to practice core JavaScript concepts, DOM manipulation, and responsive UI design.

Inspired by the [Scrimba](https://scrimba.com/) JavaScript curriculum project. After following the initial walkthrough, I rebuilt the game independently to reinforce my understanding of game logic, arrays, and event handling.
